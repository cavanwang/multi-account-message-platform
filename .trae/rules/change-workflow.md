# 代码修改工作流

1. **强制规划**：对于任何涉及代码修改的请求，必须先进入只读研究模式，输出一份详细的修改计划（包括涉及文件、具体改动点、潜在影响）。
2. **等待确认**：计划输出后，必须停止，等待用户输入确切的暗号 `codecode`。
3. **禁止提前行动**：在收到 `codecode` 之前，严禁使用任何编辑工具（Edit、Write、MultiEdit）。
4. **确认后执行**：收到 `codecode` 后，严格按照已展示的计划进行修改。
5. **单次垂直功能**：每次只做一个垂直功能，做完 typecheck，再询问是否需要 commit 以及 commit 的消息内容。
