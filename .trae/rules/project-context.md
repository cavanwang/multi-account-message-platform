# 项目背景与权威文档

## 权威文档
- `docs/examination_project.md` 是完整的本项目要求。本项目是一个招聘全栈程序员的笔试项目，要求 48 小时完成。一切实现以它为准。
- 每次开始一个任务前，先读一遍相关章节。

## 运行环境
- Trae 跑在宿主机。
- 整个笔试项目的实现采用 docker-compose 一键部署；测试程序/脚本可以使用宿主机的 bash/python 脚本，但脚本只调用容器服务，避免脚本太重。
- 交付物必须可以通过 docker-compose 一键部署，以便面试官快速验证笔试项目是否符合预期。
